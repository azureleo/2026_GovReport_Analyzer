## 1. 중간보고 이후 진행 개요

중간보고서의 결론이었던 하이브리드 아키텍처(프로그램 방식의 뼈대 + LLM의 유연한 추론)를 실제 구현했습니다. 문서 파싱 → 시트별 페이지 라우팅 → 텍스트·표 LLM 추출 → 이미지 triage·비전 판독 → 결정론적 정제/검증(Python) → 빈칸 보완(Gap-Fill) → Excel 출력의 구조이며, 환경부 가이드라인을 기계 파싱해 시트별 프롬프트에 구조적으로 주입합니다.

이후의 작업은 크게 세 국면입니다.

1. **측정 체계 구축**: 정답지(골든셋)·채점기·시각 인벤토리 감사 도구를 만들어 "얼마나 정확한가"를 숫자로 답할 수 있게 함
2. **정합 개선 라운드**: 측정이 지목한 오류(값이 잘못된 행·수준으로 가는 문제)를 라운드 단위로 교정 — 모든 수정은 3개 지자체 회귀 게이트 통과 시에만 채택
3. **일반화(진행 중)**: 정답지가 없는 지자체의 품질을 자동 추정하는 무골든 검증 체계 구축

## 2. 측정(벤치마크) 체계 설계

정확도를 재기 위해 만든 도구 4종입니다. 모두 LLM 호출 없이(비용 0) 동작합니다.

### 2.1 서울 골든셋 — 정답지 구축

사람이 처음부터 만들면 수일이 걸리므로, **독립 추출 3종(서로 다른 모델·방식)의 교차합의**로 초벌을 만들고 불일치는 전량 원문 판정으로 확정했습니다. 이후 가이드라인 산식(감축률 = (기준배출량−목표배출량)/기준배출량)으로 전 행을 검산해 오류 행을 교정했습니다.

- 채점 대상 **3,520행** (16개 데이터 시트), 시각(차트) 유래 정답 312행 포함
- 시각 요소 인벤토리 **176개** (본문 캡션 505건에서 사람+AI 3라운드 교정으로 확정)

### 2.2 골든셋 채점기 — 시트별 리콜·정밀도·값일치율

파이프라인 출력과 골든셋을 자동 대조합니다. 행 매칭은 4단 티어(엄격 키 일치 → 완화+값 검증 → 의미완화(토큰 유사도) → 문자유사)로, 느슨한 티어일수록 값 일치를 전제해 **가짜 매칭이 점수를 부풀리지 못하게** 설계했습니다. 수치는 상대오차 0.5% 이내를 일치로 봅니다.

### 2.3 시각 요소 인벤토리 감사 — 차트를 어느 단계에서 놓치는지

문서의 모든 차트·이미지표 176개에 대해 이미지 추출 → 선별(triage) → 비전 판독 → 기록의 어느 단계에서 유실됐는지 요소 단위로 추적합니다.

### 2.4 무골든 품질 프로브 — 정답지 없는 지자체용 (신규)

독립 백엔드 2개가 같은 키에서 같은 값을 내는 비율(**교차 백엔드 합의율**)을 측정합니다. 서울에서 "합의율 ↔ 골든 정확도"의 대응 관계를 보정(캘리브레이션)하면, 정답지가 없는 지자체의 정확도를 **하한 밴드로 추정**할 수 있습니다(4장).

## 3. 벤치마크 결과

### 3.1 차트 판독(VLM) 교차 프로바이더 벤치마크

동일 문서·동일 조건(통제 조건)에서 비전 모델만 교체해 시각 요소 판독 리콜을 실측했습니다.

| 비전 모델 | 판독 리콜 | 소요 시간 | 비고 |
|---|---:|---:|---|
| **gemini-2.5-pro** | **0.976** | 1,282s | 1위 — API 모드 기본값으로 채택 |
| **gpt-5.6-luna** | **0.963** | 1,300s | 에이전트(codex) 모드 기본값으로 채택 |
| gpt-5.5 (xhigh) | 0.951 | 2,869s | luna 대비 2.2배 느림 |
| gemini-2.5-flash-lite | 0.707 | – | 저비용 축 |
| gemini-2.5-flash | 0.695 | – | |

값 판독 정확도는 표본 채점(원문 대조) 기준 **0.81~0.83**, 라벨·표 인쇄형 요소는 98~100%, **사전지식 환각 0건**이었습니다. 이 실측으로 비용-성능 이원 전략(API 키만 있으면 되는 하한 구성 / 구독 기반 권장 구성)을 확정했습니다.

### 3.2 텍스트 추출 백엔드 비교 — 같은 파이프라인, 백엔드만 교체

| 지표 (서울 골든 3,520행) | gemini flash-lite (하한 구성) | **codex gpt-5.6-luna (권장 구성)** |
|---|---:|---:|
| 텍스트 유래 리콜 | 0.610 | **0.845** |
| 값일치율 (텍스트 유래) | 0.886 | **0.928** |
| 시각 유래 리콜 | 0.169 | **0.238** |
| 06_감축목표 값일치율 | 0.50 | **0.88** |

리콜 격차 +23pp는 파이프라인이 아니라 **백엔드 등급이 지배**하는 격차임을 확인했습니다(팀원의 GPT-5.5 독립 실측도 리콜 0.87/값일치 0.90으로 같은 등급대 — 판정골든 1,760행 축). 이에 따라 `--agent codex` 실행 시 텍스트·비전 모두 luna를 기본값으로 채택했습니다.

### 3.3 정확도 개선 여정 — 측정이 이끈 라운드들

측정 체계가 지목한 최대 오염원은 06_감축목표 시트였습니다. 값불일치 22쌍을 전수 원문 판정한 결과, 연차별 경로표·사업카드의 값이 부문 목표 행으로 유입되는 것이 실원인이었고, 키 분리(재태깅)·프롬프트 개정·채점기 정직화로 해소했습니다.

| 06_감축목표 값일치율 | 0.15 → 0.20 → 0.50 → 0.87 → **0.88** |
|---|---|
| 시각 유래 리콜 (차트 값의 본 시트 편입) | 0.013 → 0.166 → **0.238** (18배) |
| 서울 03 시트 값일치율 (가스종 오염 제거) | 0.60 → **0.93** |

주: 라운드마다 채점 기준도 함께 엄격해졌으므로(가짜 매칭 제거) 위 수치는 보수 방향으로 정직한 개선입니다.

### 3.4 차트 값의 본 시트 자동 편입 — "값 오병합 0" 정책

차트에서 읽은 값을 데이터 시트에 자동 편입하는 것은 오염 위험이 커서, 게이트(라벨 기반·키 완성·텍스트 교차검증)를 통과한 값만 병합합니다.

| 지자체 | 병합 | 생략 | 경고 | 차단(16시트 보존) |
|---|---:|---:|---:|---:|
| 서울 | 209 | 15 | 0 | 1,320 |
| 강원 | 49 | 98 | 0 | 830 |
| 경기 | 213 | 2 | 0 | 1,912 |

전 국면을 통틀어 **값 오병합(잘못된 값이 본 시트에 들어간 사례) 0건**을 유지했습니다. 차단된 판독값도 버리지 않고 16_시각자료목록 시트에 전량 보존되어 사람이 검토할 수 있습니다.

## 4. 일반화 — 3개 지자체와 무골든 검증

### 4.1 3개 지자체 완주

서울·강원·경기 3개 문서 모두 사람 개입 없이 전 구간 완주했습니다(추출 배치 383/245/393건 전수 성공, 호출 실패 0). 모든 코드 수정은 "특정 지자체 하드코딩 금지 + 3개 지자체 회귀 게이트"를 통과해야 채택되며, 실제로 서울 전용 가정(관리번호 체계 의존 등)을 이 게이트가 찾아내 교정했습니다.

### 4.2 무골든 정확도 추정 — 서울을 자(尺)로 쓰는 캘리브레이션

서울은 골든 정확도와 교차 백엔드 합의율을 둘 다 갖고 있으므로 대응 관계를 실측했습니다. 결과: 수치 시트 9개 중 8개에서 **합의율이 골든 값일치율의 보수적 하한**으로 작동(최대 역전 −3.8pp). 이를 근거로 추정 규칙 **"값일치율 ≥ 값합의율 − 4pp"** 를 채택하고, 정답지가 없는 강원·경기에 첫 정량 추정을 산출했습니다.

| 시트 (발췌) | 강원 추정 값일치율 | 경기 추정 값일치율 |
|---|---|---|
| 02_지역여건 | ≥ 0.88 | ≥ 0.87 |
| 04_배출현황(관리권한) | ≥ 0.87 | ≥ 0.61 |
| 10_정량감축량 | ≥ 0.87 | ≥ 0.94 |

합의율이 낮은 시트는 자동으로 사람 표본 검증 대상(지자체당 30행)으로 지정됩니다 — 전수 검수가 아니라 신호가 약한 곳만 사람이 보는 구조입니다.

## 5. 신뢰성 인프라 (숫자 밖의 성과)

- **자동 테스트 381개**: 모든 커밋이 전체 테스트를 통과(bisect 안전). 신뢰성 계약(부분 실패 허용·quota 복구)부터 병합 게이트·채점기 계약까지 회귀를 차단합니다.
- **재현성**: LLM 응답 캐시로 동일 실험을 비용 0으로 재실행, 산출물에 git 커밋·모델 계보 자동 기록.
- **자기 감사**: 행 단위 데이터상태(visual_only·conflicting 등)와 검증리포트(합계 검산·단위 혼재·중복 충돌)가 사람이 재확인할 행을 직접 지목합니다. 팀원의 PDF 역추적 검수도구와 결합해 서울 산출물 7,308행 확인을 완료했습니다.
- **개발 프로세스**: 명세서 작성 → 구현 → 독립 재검증 → 3지자체 실측 게이트의 4중 방어를 전 라운드에 적용해, 결함이 병합 전에 걸러졌습니다.

## 6. 남은 과제

1. **계약 확인 3건(발주처 문의 준비 완료)**: 배출유형 미표기 차트의 배정 규칙, 점검실적 달성여부 코드 매핑, 같은 기준연도의 복수 인벤토리 축 구분 — 현재 잔존 오차의 다수가 코드가 아니라 이 계약 결정에 달려 있습니다.
2. **무골든 추정의 사람 검증**: 지자체당 30행 표본 원문 대사로 추정 밴드를 실증(진행 중).
3. **수렴 루프(M4)**: 측정→수정→재측정 반복으로 목표 정확도 도달 후 실무 투입(사람은 시스템이 지목한 행만 확인).
